# Reviewed context and selected portable handoff

Date: 2026-10-24. Status: adopted and implemented.

Authority: Zayan approved completing source coverage, evaluation, context preparation, onboarding and migration in that order in codex:01a16510-7f12-78b0-afa9-d5aee24d915b. When asked about the migration target, Zayan selected “Portable bundle first.” No ChatGPT export is available; Muse remains deferred.

New users initialize their own workspace with source capture disabled unless explicitly selected. Application defaults and public development guidance contain no personal project registry or preferences. This installation retains its private operating instructions in workspace/AGENTS.md. A generated ASSISTANT.md explains optional local assistant access; its presence does not establish activation in any provider.

AI-prepared context is an inspectable, provenance-bearing artifact. Import retains it unreviewed; explicit acceptance records a review note before publishing a reusable context note. Acceptance does not install host instructions or claim access to provider-internal memory.

Migration produces a new local directory with readable Markdown, structured records, separate annotations and a hashed manifest. Selection must be explicit: named conversations, one registered project, or all captured conversations. Context is opt-in and excludes unreviewed inbox material. Stable source/message identities, source text, capture limits and reviewed-context provenance travel with the selection. Attachment bytes, historical revisions, provider snapshots, installed skills and schedules do not.

This format can be read independently of ChatOS and verified locally. It avoids assuming a destination application's native import schema. Destination-specific import, upload, account synchronization and memory activation remain outside this implementation. Hash verification detects corruption rather than proving authenticity; original messages and annotations can still contain personal information and need review before sharing.
