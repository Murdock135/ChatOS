# Behance reference observations

Research date: 2026-11-06. Source instruction: Codex conversation `01a1b32b-dcb2-7823-bdb5-159c764aeb53`, “for designing, style and colors, go to behance and take inspiration from there”. The projects below are external creative work, not smriti designs.

## Access and evidence

Search located the projects and direct Behance CDN images. Opening the three initially selected gallery pages through the web reader returned HTTP 403; the browser host was unavailable. A native Chrome follow-up failed screen capture. Three direct project images were downloaded to temporary storage and actually inspected with the image viewer. The image URLs and SHA-256 identities are retained in [reference receipts](evidence/v1.1/reference-receipts.json); the reference artwork is not bundled with the app or public archive.

Descriptions below separate visible observations from smriti's own implementation decisions. Indexed descriptions supplied the project titles and available creator metadata. No complete case study, Figma file, exact typeface, sampled color system, responsive behavior, or accessibility result is claimed.

## ImeSas — AI Agent & SaaS Analytics Dashboard

[Behance project](https://www.behance.net/gallery/247104579/Imesas-AI-Agent-SaaS-Analytics-Dashboard-Design) · [inspected image](https://mir-s3-cdn-cf.behance.net/project_modules/fs/75241b247104579.69d3e065c4190.jpg). Indexed project credit: Md Sahadot.

Observed in the image: a navy dashboard; rounded outlined metric/chart panels; light text; vivid green selected navigation and plotted data; purple used as a second data series; clear alignment between the navigation and content.

Adapted for smriti: keep dark surfaces and use one mint interaction color with a restrained secondary lilac. Retain visible card hierarchy and readable state text. The softer graphite/mint values are chosen for smriti, not extracted from this image. Analytics metrics, chart content and sidebar labels are not adopted.

## Project & Client Management Dashboard — Dark UI

[Behance project](https://www.behance.net/gallery/237697241/Project-Client-Management-Dashboard-Dark-UI) · [inspected image](https://mir-s3-cdn-cf.behance.net/project_modules/fs_webp/41a82b237697241.6905d29f38f9f.png). Indexed project credit: Saiful Islam; a matching personal profile was not independently established.

Observed in the image: nearly black surfaces; warm gold edge illumination around the upper dashboard; tightly grouped rounded panels; compact icon navigation; a distinct right-hand scheduling area; pill-like actions and selective warm accents.

Adapted for smriti: softer panel grouping and low-intensity edge highlights, while keeping the working area calm. Warm status accents remain secondary. The strong decorative gold flare and unrelated scheduling/finance widgets are not included.

## BES — AI-Powered B2B SaaS Dashboard

[Behance project](https://www.behance.net/gallery/229197739/BES-AI-Powered-B2B-SaaS-Dashboard-Design) · [inspected image](https://mir-s3-cdn-cf.behance.net/project_modules/1400_webp/85c99b229197739.68608820a59ec.png). Creator attribution was not established from accessible metadata; credit remains with the linked project and its owner(s).

Observed in the image: a light dashboard presentation with purple emphasis, rounded grouped surfaces, pastel status icons, a distinct top search/control row, and clear separation between controls, metrics and longer data sections.

Adapted for smriti: lilac for secondary identity and restrained metadata, and clear separation between search controls and records. The source's light palette is not treated as a dark-mode reference. No claims are made about its actual AI capabilities or accessibility.

## Implemented synthesis

v1.1 uses graphite canvas/surfaces, mint primary actions, lilac secondary identity, and a calmer multi-topic map palette. Typography, spacing, the supplied smriti branding, existing app structure, and the user's architectural Home reference continue to govern the UI. The central ChatGPT illustration remains inert. References inform visual decisions; they do not authorize new features, provider access, or data changes.
