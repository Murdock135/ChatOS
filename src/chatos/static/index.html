Workspace health

Run outcome and source coverage are separate. A healthy database can still contain partial captures.

1. Choose your sources

Use Settings → Import chats for a ChatGPT export. Local Codex history is optional. Saving a source choice does not scan it; select Sync workspace when ready.

2. Choose assistant access

An assistant with local file access can use your workspace through ASSISTANT.md. Give that file to your chosen assistant; creating it does not connect an account or activate memory.

Let your Chief of Staff use smriti through its reusable skill. New workspaces include a copy connected to their paths. Preparing the folder does not install it in your assistant.

Load the skill in your assistant

Give the assistant the full SKILL.md path and ask it to read and use it. In Codex, you can instead copy the whole chatos folder to your project's .agents/skills/chatos or your own ~/.agents/skills/chatos, preserving the references and agents folders. Do not replace a folder you have customized. Verify that chatos appears in the skill picker, then try: Use $chatos to find our earlier discussion about my current project and cite the messages. Skill instructions need local file and terminal access; a hosted chat cannot read this folder automatically.

3. Review reusable context

Import a context JSON artifact prepared from visible conversations. Inspect its text, sources, scope and uncertainty before accepting it. Accepted notes become searchable; they are not installed as host instructions.

Ask your AI to prepare an artifact

Use only messages and files you can actually inspect. Separate explicit preferences from suggestions. Return JSON with schema_version: 1, kind: profile, preferences or project_context, body, created_at (ISO timestamp with timezone), generated_by, source_references (list), and uncertainties (list). State missing evidence; do not claim access to hidden memory. I will review before accepting.

4. Take context to another app

Create a verified local folder of Markdown and JSON. Nothing is uploaded. Review it before supplying files to another assistant. Missing messages and attachments are not recovered.
